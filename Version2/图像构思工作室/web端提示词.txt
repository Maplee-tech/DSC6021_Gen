请开发一个名为 Prompt Book 的 3D 立体书 AI 生图提示词优化器前端片段页面。

注意：这不是普通的 3D 展示模型，也不是把几张插画贴在网页上。书本本身就是这个产品的界面容器：合上的书 → 点击打开 → 左页是生成图像，右页是 VLM 评分、快捷补丁与用户补充输入，书前桌面是 15 张 IR 字段卡片，书页左侧边缘是历史版本时间轴。需要实现真实可操作的 3D 场景与完整的打开、悬停展开、点击迭代过程。

【一、整体视觉】
高品质 3D 纸艺绘本风格 + 极简科技感：浅木色桌面、低饱和度鼠尾草绿桌垫、奶油白纸张、奶油黄色精装书封面、精细印刷文字。
柔和自然光，真实环境遮蔽与接触阴影；整体温暖、精致、安静，避免霓虹赛博朋克、夸张游戏 UI 和廉价卡通素材。
主题色（所有按钮、标签、进度条、高亮均严格使用这三色）：
- 主色 琥珀金 #D89B3C（主按钮、当前选中项、置信度高亮）
- 辅色 鼠尾草绿 #8FA37A（次按钮、成功态、桌垫同源色）
- 深色 墨棕 #4A3B2A（正文、描边）
背景纸白 #FBF6EA，禁用的低置信度用 #C9BBA8 灰化。
按钮不使用默认蓝色，hover 时底色加深 8%，按下时缩放 0.97 + 内阴影。

【二、书本结构与打开动画】
完整精装书：封面、封底、书脊、纸张厚度、内页、书签。初始完全合上，平放在桌垫中央，书脊在左。
点击封面后 1.2～1.6 秒缓慢打开，带轻微加速减速；封面绕书脊轴 3D 旋转，内页用分段顶点弯曲模拟纸张弧面，不要硬纸板式整体翻转。
打开后呈左右对开：左页 = 生成图像区，右页 = VLM 评分与用户补充区。书页边缘有厚度，中缝有自然阴影。
书打开状态下，鼠标移动时整本书围绕 X/Y 轴做 ±0.05rad / ±0.03rad 的克制倾斜，配合页面元素分层视差（左页图像层 ±0.04rad，右页文字层 ±0.02rad）。
鼠标离开或点击"合上"时平滑复位，书本合上回到初始状态。

【三、左页：生成图像（核心展示区）】
左页中央以"印刷在纸上"的方式展示生成的图像：
- 图像区域宽度占左页 78%，居中对齐，四周留白充足；
- 图像带 1px 奶油色内边距和极淡的纸张纹理叠加，模拟油墨渗透；
- 图像四角有极细的纸面翘曲阴影，让图像像真实印在书页上而非贴上去；
- 图像下方一行小字：当前 Prompt 摘要（如"赛博朋克风格书店 · 雨夜街区外景 · 16:9"）；
- 图像右下角有极小的页码与版本号（如"v3 · 03/07"）；
- 点击图像可在"当前版本"与"上一版本"之间切换对比，切换时纸张轻微翻动 0.3 秒，图像以 0.25s 交叉淡入淡出。

【四、右页：VLM 评分 + 快捷补丁 + 用户补充】
右页内容自上而下分四段，整体左右留白一致：
1. 顶部对比提示（一行小字）："当前 Prompt 期望：全息招牌，AI 画成了普通霓虹灯"。
2. 评分区：4 个维度卡片按 2×2 网格紧凑排列，每个卡片包含：
   - 维度名（主体一致度 / 风格契合度 / 细节命中率 / 综合推荐度）；
   - 5 星制星级 + 细进度条（进度条用琥珀金到鼠尾草绿渐变，低于 60% 用暖灰）；
   - 分数数字右对齐。
3. 快捷补丁标签区（Chips）：
   - 标签文字来自 VLM 的具体扣分项，如"缺少电缆""文字乱码""霓虹感不足"；
   - 标签为鼠尾草绿描边胶囊，一行流式排列，超出一行自动换行；
   - hover 时背景填充 15% 绿；
   - 点击标签时，标签以 0.35s 飞入动画（位移动画 + 缩小消失）落入下方文本输入框，输入框自动拼接成完整句子："在原有基础上，增加错综复杂的电缆细节"；
   - 已应用的标签变为琥珀金描边 + 禁用态，避免重复添加。
4. 用户补充输入区：
   - 多行文本输入框（3 行高），占位文字"补充你想要的调整，或点击上方标签快速生成"；
   - 输入框下方右侧为"应用并重新生成"主按钮（琥珀金实心），左侧为字符计数；
   - 点击主按钮后按钮进入 loading 态（文字变"生成中…"+ 轻微脉冲），完成后右页内容整体刷新、书签新增一条。

【五、书前桌面：15 张 IR 卡片（核心交互）】
书的前方桌面上，横向排列 15 张 IR 字段卡片，像散落在桌上的索引卡：
- 默认状态：每张卡片收起为窄条（宽 52px、高 150px），只显示字段名竖排 + 顶部置信度小圆环（<50% 暖灰，50-80% 琥珀金，>80% 鼠尾草绿）+ 来源小图标（用户 / 推断 / 默认）；
- 鼠标悬停到某张卡片：该卡片以 0.28s 弹性缓动横向展开到 260px，显示字段值、来源标签、置信度百分比、可选 options 胶囊；
- 悬停离开：平滑收回 52px 窄条；
- 同一时间只允许一张卡片展开，其他卡片保持收起；
- 点击 options 胶囊：该卡片值实时更新，置信度圆环颜色随之变化，左页图像区短暂闪烁（0.3s 边框琥珀金脉冲）以提示"参数已变更"；
- 卡片有真实纸张厚度（1px 底部加深边）和轻微投影，排成一排时整体略微倾斜贴合桌面透视。
15 张卡片字段（按序）：
1 主体 2 场景 3 风格 4 构图 5 光照 6 细节 7 负面提示 8 比例 9 色调 10 材质 11 镜头 12 氛围 13 时代 14 人物 15 环境
字段值与选项示例：
- 主体：书店 / 书架与书籍 · 用户 · 95%
- 场景：雨夜霓虹街区外景 · 推断 · 45% · 选项：雨夜街区外景 / 书店室内 / 室内外结合
- 风格：赛博朋克，写实概念艺术 · 用户+推断 · 80% · 选项：写实概念艺术 / 动漫插画 / 3D 渲染
- 构图：广角、平视、16:9 · 默认 · 50%
- 光照：霓虹青 / 洋红，湿润反光，店内暖光对比 · 推断 · 60%
- 细节：全息招牌 / 电缆 / 密集城市 / 书籍细节 · 推断 · 50%
- 负面提示：低清晰度 / 模糊 / 畸形 / 乱码文字 / 过曝

【六、书页左侧边缘：历史版本时间轴】
书页左侧外缘夹 4～5 条鼠尾草绿书签缎带，代表历史版本，紧邻左页图像区：
- 每条缎带露出 40px，hover 时向外滑出 60px，显示该版本缩略图 + 综合评分；
- 点击缎带可回看该版本图像（左页图像交叉淡入切换），当前版本缎带为琥珀金并略微高出；
- 新一轮生成时，新缎带以 0.4s 滑入动画插入到最上方；
- 缎带 z-index 低于右页输入框，避免遮挡鼠标操作路径。

【七、底部控制栏】
简洁半透明胶囊控制栏，居中固定在页面底部：
- 主按钮"重新生成"（琥珀金实心）
- 次按钮"合上书本 / 打开书本"（鼠尾草绿描边）
- 次按钮"对比模式"（鼠尾草绿描边，激活时实心）
- 音效开关图标
- 所有按钮圆角 999px，高度 40px，图标 + 文字，hover 有 0.2s 阴影浮起。

【八、交互与动画要求】
所有状态切换使用 0.25～0.4s 的 cubic-bezier(0.22, 1, 0.36, 1) 弹性缓动，避免线性动画。
卡片展开、chip 飞入、书签滑出、书本开合、图像切换五类动画节奏必须统一，不要出现某类动画过快或过慢。
页面加载后书本先有 0.6s 浮入动画（从上方 20px 落下 + 透明度 0→1）。

【九、技术实现与性能】
输出可直接运行的单 HTML 文件，用 CSS 3D（perspective: 1600px、transform-style: preserve-3d、rotateX/rotateY）实现书本与卡片的空间感，用原生 JS 驱动状态；不需要引入 Three.js。
所有 hover 展开用 CSS transition，不用 JS 逐帧改样式；书签与 chip 飞入用 Web Animations API。
窗口 resize 时保持书页内容等比缩放；系统开启 prefers-reduced-motion 时关闭所有位移类动画，仅保留透明度过渡。
禁止使用默认蓝色按钮、禁止霓虹渐变、禁止大面积纯黑背景。

【十、验收标准】
1. 打开页面先看到合上的黄色精装书，桌面、桌垫、书签和阴影完整。
2. 点击书本 1.2～1.6 秒内自然打开，左页图像、右页评分与输入区、15 张卡片、书签同时就位，无闪烁无穿模。
3. 左页图像呈现"印刷在书页上"的质感，带纸张纹理、边缘阴影和版本号，点击可在当前/上一版本间交叉淡入切换。
4. 右页评分卡为 2×2 紧凑网格，chips 一行流式换行，已应用标签变为琥珀金禁用态。
5. 鼠标悬停任意一张 IR 卡片，该卡片 0.28s 弹性展开到 260px，其他卡片保持 52px 收起状态；移开后平滑收回。
6. 点击"快捷补丁"标签，标签以飞入动画落入右页输入框并自动拼成完整句子，点击"应用并重新生成"后左页图像刷新、左侧书签新增一条。
7. 所有按钮、进度条、标签严格使用琥珀金 #D89B3C、鼠尾草绿 #8FA37A、墨棕 #4A3B2A 三色体系，无默认蓝色。
8. 鼠标移动时整书与页面元素有克制分层视差，鼠标离开后平滑回中。
9. 移动端可用，文字清晰，动画流畅不掉帧。

不要做成霓虹赛博朋克、游戏 HUD、静态插画轮播或只有 CSS 倾斜的伪 3D。请启动页面、逐条检查卡片展开、chip 飞入、书签滑出、书本开合、图像切换五类动画的手感，发现问题后反复修复再交付，并附上关键参数说明（动画时长、缓动曲线、卡片展开宽度、视差幅度）。
